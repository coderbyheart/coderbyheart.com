> Error messages are the only piece of documentation you can be sure people will
> read when it is relevant. Write them accordingly.  
> — [_Beth Andres-Beck_](https://twitter.com/bethcodes/status/1303409425554665474)

Use [RFC 7807 "Problem Detail"](https://tools.ietf.org/html/rfc7807) to document
API errors.
